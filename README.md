A tiny program that writes one short poem about agency: the power to act, handed over for a night and handed back by morning. It writes the poem to `entry.txt`, byte for byte the same on every run.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
